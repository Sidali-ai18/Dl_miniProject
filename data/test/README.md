# Test Data

Place your test images here, organized by emotion.

## Directory Structure

```
test/
  ├── happy/
  │   ├── person1_happy_test1.jpg
  │   └── ...
  ├── sad/
  ├── neutral/
  └── [other emotions]/
```

## Tips

- Use 20-30% of your total images for testing
- These should be images the model hasn't seen during training
- Use the same emotion categories as in training data
- Test images help evaluate model performance on new data
